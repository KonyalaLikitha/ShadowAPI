# Contributing to ShadowAPI

Thank you for your interest in contributing to ShadowAPI.

---

## Getting Started

1. Fork the repository
2. Clone your fork

```bash
git clone https://github.com/KonyalaLikitha/ShadowAPI.git
```

3. Install dependencies

```bash
npm install
```

---

## Project Structure

```bash
shadowapi/
 ├ engine/
 ├ gateway/
 ├ cli/
 ├ extension/
 ├ examples/
 ├ docs/
```

---

## How to Contribute

* Fix bugs
* Improve UI/UX
* Add features
* Improve documentation

---

## Commit Guidelines

Use meaningful commit messages:

Good examples:

```
feat(extension): add request grouping
fix(gateway): handle missing endpoints
docs: update README
```

Avoid:

```
update
fixes
final
```

---

## Pull Request Process

1. Create a new branch

```bash
git checkout -b feature-name
```

2. Commit your changes

3. Push to your fork

4. Create a Pull Request

---

## Code Style

* Keep code clean and readable
* Use meaningful variable names
* Follow existing project structure

---

## Reporting Issues

If you find a bug:

* Describe the issue clearly
* Add steps to reproduce
* Include screenshots if needed

---

Thank you for contributing to ShadowAPI.
